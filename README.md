雨课堂刷课助手



图形界面的雨课堂自动刷课工具：自动刷视频进度，可选 AI 自动回答讨论、完成练习。
功能
🖥️ 图形界面，不用敲命令行
🍪 两种登录：浏览器扫码登录自动抓取 Cookie / 手动粘贴 Cookie
✅ Cookie 一键验证，登录状态实时可见
💬 讨论、练习可单独开关；只刷视频不需要任何 Key
🤖 勾选讨论/练习后，调用 DeepSeek 自动作答
📺 独立日志弹窗，刷课进度实时显示，支持断点续刷
😴 刷课时自动阻止电脑休眠，可放心挂机



使用教程

第一步：打开软件
双击 YuketangHelper.exe 即可，不需要安装 Python 或任何其他东西。
Windows 首次运行可能弹出"未知发布者"警告（个人打包的软件都没有签名，都这样）：
点击"更多信息" → "仍要运行"。

第二步：登录（二选一）

方式一：浏览器登录（推荐）
点 ① 浏览器登录，会弹出一个 Chrome 窗口
在这个弹出的窗口里扫码登录雨课堂（注意：必须在这个窗口里登录，在你自己平常用的 Chrome 里登录是没用的）
等页面跳转到已登录状态，回到软件点 ② 我已登录，自动获取 Cookie
自动验证通过会提示"登录成功"，Cookie 自动保存

方式二：手动粘贴 Cookie
在浏览器里登录雨课堂后，复制你的 Cookie 字符串
粘贴到软件的 Cookie 输入框
点 ③ 验证 Cookie 是否有效，提示"登录成功"即可
Cookie 会过期，提示无效时重新登录获取一次就行。


第三步：选择功能
只想刷视频：两个勾选项都不勾，不需要填任何 Key
要 AI 写讨论：勾选"处理讨论学习点"，并填写 DeepSeek Key
要 AI 做练习：勾选"练习学习点"，并填写 DeepSeek Key
DeepSeek Key 获取：到 platform.deepseek.com 注册账号，在 API Keys 页面创建一个（新号有免费额度）。
第四步：选课并开始
点"刷新课程列表"
在列表里单击选中一门课
点"开始刷课"，会自动弹出深色的运行日志窗口
可以最小化挂机，刷完会提示；中途点"停止"可暂停，下次从断点继续

第五步：查看进度
运行日志窗口可自由缩放，实时显示每节课的进度
主窗口底部状态栏显示最新一条动态
日志窗口点 X 只是隐藏，点"查看运行日志"可再调出来

常见问题
Q：杀毒软件报毒？
A：PyInstaller 打包的个人小软件经常被误报，添加信任/放行即可。软件不联网上传任何你的数据（见下）。
Q：我的数据会上传到哪里吗？
A：不会。Cookie 和 Key 只保存在软件旁边的 user_config.json 里；软件只和雨课堂服务器（上报进度）以及 DeepSeek 服务器（勾选问答功能时，把题目发过去换答案）通信。不要把 user_config.json 发给别人，里面是你的登录凭证。
Q：电脑没有安装 Chrome？
A：点 ① 会提示你先安装 Chrome，或者改用手动粘贴 Cookie 的方式登录。
Q：可以同时刷两个号吗？
A：两个不同账号可以一起跑，但要把 exe 单独放在不同文件夹里（避免配置文件互相覆盖）。同一个账号不要双开，两边会互相顶，还可能被平台风控。
Q：刷课会被检测吗？
A：任何自动化工具都有被平台检测的可能，请自行评估风险。建议不要在考试等敏感场景使用。
Q：讨论/练习一定要填 Key 吗？
A：只有勾选了对应功能才需要。不勾选的话，程序会自动跳过，只刷视频。
